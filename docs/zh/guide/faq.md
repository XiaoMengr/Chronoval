# 常见问题（FAQ）

## 外部库（本地目录）和本地存储有什么区别？

两者是两种完全不同的照片存取方式，最直观的差别是：

| 维度 | 本地存储（加密上传） | 外部库（本地目录引用） |
| --- | --- | --- |
| 照片来源 | 通过程序后台上传 | 直接放入一个已有文件夹 |
| 文件是否移动 | 是，文件被复制进程序管理的存储 | 否，原文件留在**你的**目录里 |
| 是否加密 | 是，以加密 blob 存储，只有程序能读取 | 否，完全保持原样明文 |
| 是否修改原文件 | 原图经上传处理 | 绝不改写、不搬移、不加密原文件 |
| 播放/识别 | 只有程序能识别读取到照片 | 放进即自动识别展示，外人直接浏览目录也能看 |
| 缩略图 | 存在程序存储内 | 在原目录旁就地生成 `thumbnails/` 子目录，不动原图 |

### 外部库（本地目录引用）是什么

外部库指的**不是**"把照片传进程序"，而是把一个**已有的文件夹直接挂载引用**进来。例如你有个目录 `家庭相册/`，里面放着一堆照片，只要把这个目录添加为外部库：

- 程序**只读引用**，原文件夹里的照片完全不被加密、不修改、不搬移，始终是原来的明文文件
- 自动扫描识别其中的照片，并在相册目录下**就地生成缩略图**（如 `家庭相册/thumbnails/`）用于加速展示，缩略图是额外新增，不影响任何原图
- 目录结构即相簿：每个文件夹自动汇聚成一个相簿，照片直接预览成相册
- 特点：**程序依赖这个目录存在**。如果你把目录删了/移走，程序就看不到这些照片了

这就是"文件夹里有照片，直接添加外部库识别"的用法。

### 本地存储（加密上传）是什么

本地存储是**上传模式**：照片通过程序后台上传后，被**加密**保存到程序自己的存储目录里：

- 照片以加密 blob 形式存储
- **只有程序能识别、读取到这些照片**，未授权无法直接读取原图（支持缩略图遮罩预览）
- 原件与外部库的明文文件是完全隔离的两套体系

### 一句话分清

> **外部库**：你的文件夹，程序"借来看"，照片原样、明文、不加密，目录删了照片就没了；程序只在旁边加缩略图。
>
> **本地存储**：上传进程序的照片，程序"加密保管"，只有程序能读，与你的原始目录无关。
